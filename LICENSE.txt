Os dados neste directório são uma base de dados derivada, construída a partir de:

  * DGEG — Direção-Geral de Energia e Geologia (preços declarados pelos operadores)

O OpenStreetMap é distribuído sob a Open Database License (ODbL), que é
share-alike. Por isso este ficheiro derivado é também distribuído sob a ODbL:

Isto cobre a base de dados, não o software que a consome.

OpenStreetMap Foundation.
